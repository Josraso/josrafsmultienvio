# josrafsmultienvio

Plugin de FacturaScripts (2025.71 o superior) para enviar los documentos desde varias cuentas SMTP, cada una con su propio formato de documento: logo, titulo y texto de pie.

La configuracion esta en **Panel de control > Email**, en las pestañas "Cuentas de envio" y "Opciones del multienvio". No añade entradas nuevas al menu.
